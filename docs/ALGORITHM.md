# semantic V4.5 R3 算法

最终方案入口为 `semgt.runner`。XODR-only V4.2 世界几何、结构边界连接、实例组织和模型采样分别记录，不将几何校验当成语义精度。

## XODR 基线

每条 roadMark 按所属 laneSection 起止范围采样，保留完整 XYZ 和道路局部属性。V4.2 保留原生 divider、boundary、横道和中心线；只对 divider 做基于同类漆线、颜色、道路拓扑及道路面支持的连接。V4.1 的表面选择、被拒线恢复和全局 XY 并集不作为当前默认链。已有接触的原生实例可保持分开，后续 target 层再整理。

## boundary

从同地图、指纹固定的 V4.2 road-local boundary 候选开始。semantic ID 与实测 depth 只验证结构端点间的连接，不能独立产生新的观测轮廓。候选在完整实测参考范围内按 XODR 拓扑和端点方向生成，默认不设固定米数搜索上限；完成连接后再裁回原 BEV。多组 Hermite 种子经道路／非道路界面法向动态规划拟合，再从语义界面坐标移回局部 XODR 外缘。两端偏移分别从可靠原生线尾估计并平滑插值，不采用统一肩宽。输出 Z 使用原生端点和坡度，实测高程只验证语义参考线，避免将路缘顶部高度混入输出。道路开口、两侧角色、层高、深度、有限细杆遮挡、相交和歧义检查保留；所有原生顶点与锚点不变。详见 [boundary 对齐](BOUNDARY_ALIGNMENT.md)。

单向参考线可能位于 sidewalk 背侧。当前保留基础候选，按已知非道路前缀设置有界上下文；这不保证候选本身分类正确。此类错线需结合 XODR 和顶视图人工核对。

## R3 target 组织

只在同一类别内处理完整 XYZ。严格重复、完整包含片段先归并来源；再用 0.00001m 端点容差和最多 15° 方向变化构建唯一相接关系。歧义、真实分叉、裁剪面、跨层、平行线与明显转折保留。

centerline 是有向曲线：重复／包含要同向，连接只允许末端接起点，点序不反转。boundary 同一原始 parent 的有意分段不首尾合回，避免抹去急弯等几何切分。原始输入 targets 和来源链可追溯。

## 采样

模型采样在实例整理之后执行。完整几何与 `fixed20` / `shift_v2` 分开保存；centerline 只允许有效前向排列。固定 20 点会有表示偏差，长曲线可能更大。来源、参数和边界条件见[参数](PARAMETERS.md)、[跨地图说明](MULTITOWN.md)及[限制](../KNOWN_ISSUES.md)。
